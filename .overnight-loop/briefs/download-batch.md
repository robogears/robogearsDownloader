# The batch runner (lane batch)

Files: new files in Sources/RobogearsCore/Download/ (for example DownloadBatch.swift, BatchSummary.swift, BatchPreflight.swift, KeepAwake.swift, NetworkMonitor.swift). You may add small helpers to Sources/RobogearsCore/State/QueueItem.swift (for example a TrackDownloadRequest built from a row, a lossless flag if the row needs it for 2.10 — additive only). Tests in Tests/RobogearsCoreTests/DownloadBatch/.
Build the core of "Download All", UI-agnostic: a public actor (or @MainActor @Observable model if you can justify it for SwiftUI — say why) that runs a batch over a list of queue rows, one track at a time (as the reference's bulk runner did), through any TrackDownloading, and publishes what happens as an AsyncStream of events the UI and the queue store consume (row started / progress percent / row finished with its new QueueItem.DownloadState and message / paused waiting for the network / resumed / stopped once with a notice / finished with a summary). Rules (D4):
- 2.18 preflight, shared by Download All, Retry, Retry All and Retry Selected: download folder chosen, available (Folders.status) and not inside the library (Folders.check); TIDAL signed in. Returns either "go", "show the sign-in sheet" (signed out is the only problem) or "blocked: <plain message>" with the warning honk. The start chime is played only once the batch has really started (expose the moment; don't play sounds from core logic directly unless through an injected sound sink).
- 2.20 before a batch, check the startup disk has room for the queue save (a small threshold); per-track space is the track lane's job.
- 2.1 stop once: when a track throws an error whose stopsBatch is true, or TIDAL fails several tracks in a row (3) with .busy/.server-type errors while the Mac is online, stop the whole batch at once with ONE notice in D4's words ("Downloads stopped: your TIDAL sign-in is no longer valid. 288 tracks are still waiting…" — read 2.1 for the exact sentence shapes), and put every unfinished row back: rows that were being retried return to their earlier failed state and reason; all others to .waiting with no badge. A previewOnly failure on the FIRST track of a batch stops the batch as subscriptionInactive (2.23, 1.10); later ones just fail their row.
- 1.7 offline: an .offline error pauses — the row goes back to waiting (not failed), the batch waits for the network (an injected NetworkMonitoring protocol; a default implementation with NWPathMonitor), then retries that same track (a fresh call gets a fresh stream link). While waiting, keep-awake is released. Cancel still works while paused; a quit ends the pause.
- 2.4 cancel (also ⌘.): stops the current track at once (cancel its task; the track lane deletes the temp file), unfinished rows go back as in 2.1, never newly red; the cancel chime; done within a second.
- 2.5 quit: a method that tells the app how many tracks are still unfinished (for "Quit while 12 tracks are still downloading?") and a stop-for-quit that cancels cleanly and returns once temporary files are cleaned and the final row states are published, so the app can save the queue and quit.
- 2.13 removing a row mid-batch: a waiting row leaves the batch; the downloading row is cancelled and the batch moves on; the counter shrinks.
- 2.22 the counter counts only this batch ("37 of 120"); rows waiting in the batch get the queued state (shown as a quiet "Waiting" label). Rows added during a batch: read D4 4.12 for whether they join, and implement that.
- 2.17 the batch keeps the folder it started with; expose it for the summary's Open Folder and for Settings' "Downloads in progress are saved to …" line.
- 2.8 the ending: a pure function that turns the batch's results into the summary text and which ending sound to play — everything worked: the success ping and "Done: 12 downloaded, 2 already in your folder"; something failed: the quieter finishedWithProblems sound and "12 downloaded, 2 already in your folder, 1 failed"; nothing downloaded: the quiet sound and "Nothing downloaded: 15 failed" plus the most common reason; a stopped batch plays the quiet sound beside its notice; a cancelled batch plays only the cancel chime. It also counts the SaveNote kinds (saved as AAC, saved under another name, without cover art / limited tags, below Hi-Res). Correct singulars and plurals ("1 track", "2 tracks"). And the notification text for 2.12 ("Downloaded 47 tracks. 2 failed.").
- 2.9 row states: done / skipped / failed carry their plain message (TrackDownloadError.rowMessage; outcomes become "Already in your download folder", "Saved Blue Lantern.flac, 24-bit / 96 kHz", "Saved as Intro (Second Example).flac — another song is already named Intro", "Saved as AAC (.m4a): TIDAL has no lossless version", …); only real failures persist as failed (QueueItem.persisted already maps queued/downloading to waiting — keep that). You may need a richer DownloadState (for example a message on .done and an outcome kind for skipped/damaged/name-taken rows so the UI can offer Show in Finder / Replace / Save As…); add it additively to QueueItem.swift, keep old saved queues decoding (tolerant Codable), and list it in contract_changes.
- 2.12 keep the Mac awake during a batch: an injected SleepPreventing protocol with a default IOKit implementation (IOPMAssertionCreateWithName, kIOPMAssertionTypePreventUserIdleSystemSleep, a plain reason string), held while tracks run, released at the end, stop, cancel, quit and while waiting for the network.
Tests use a scripted stand-in TrackDownloading (results, delays and errors per row), a stand-in network monitor, sleep preventer and sound sink, and an injected clock where timing matters. Cover every rule above, including: a batch stopped by a sign-in rejection at track 1 and at track 12; retried rows restored to their earlier failure; offline pause and resume of the same track; cancel during a download and while paused; removing the downloading row; three busy failures in a row stopping the batch; preview-only on the first track vs a later track; the summary texts and sounds for each ending; the counter with Retry Selected; the keep-awake being released in every ending.
