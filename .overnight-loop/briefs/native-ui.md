# The native SwiftUI app

## Context and rules

You are building the native macOS UI of "robogears Downloader" (Swift rewrite of an Electron app that downloads lossless FLAC from TIDAL). Work ONLY in the git worktree ~/Developer/swiftRobotDownloader-lane-ui (branch loop/ui, already checked out). Never touch any other folder, never push, never switch branches, never use git -C.

Authority, in order: the owner's rules → ~/Developer/swiftRobotDownloader-lane-ui/docs/DESIGN.md (the brief) → ~/Developer/swiftRobotDownloader-lane-ui/docs/DESIGN_DIRECTION.md (the design lead's direction and build plan; follow it exactly: tokens, metrics, row anatomy and states, motion, structure, menu bar, accessibility) → HIG. Build: cd ~/Developer/swiftRobotDownloader-lane-ui/macos && xcodebuild -project RobogearsDownloader.xcodeproj -scheme RobogearsDownloader -configuration Debug -derivedDataPath build/DerivedData build — zero errors and zero warnings from your code. Do NOT launch the app normally, do not use screencapture or any screen-recording tool (they trigger permission prompts nobody is awake to answer), and do not use AppleScript/System Events.
