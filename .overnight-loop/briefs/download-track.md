# The per-track downloader (lane track)

Files: new files in Sources/RobogearsCore/Download/ (for example TrackDownloader.swift, AudioFetcher.swift, TemporaryDownloads.swift, DiskSpace.swift, TrackTagging.swift); you may ADD a streaming download-to-file method to Sources/RobogearsCore/TIDAL/HTTPClient.swift (add only; don't change existing behaviour) and a method to TIDALAPI.swift if one is missing. Tests in Tests/RobogearsCoreTests/DownloadTrack/.
Build a public TrackDownloader that conforms to TrackDownloading. It takes, by injection: the TIDALAPI (or a small protocol over the calls it needs, so tests can stand in), an HTTPClient for audio (Limits .audio), a DownloadFolderPlanning (the folder lane builds the real one; you use a stand-in in tests), an M4AWriting (the m4a lane builds it; stand-in in tests), a free-space function, and a temporary-files registry. One download, in order:
1. Folder first (2.19): the request's folder must exist, be a folder, be writable and not be in the Trash; otherwise throw .folderUnavailable with the D4 wording. Then folder.decide(for:fileExtension: nil): a .skip returns its outcome at once — no TIDAL call at all (2.16: offline can't turn a skip into a failure).
2. Track and album details (download-pipeline.md B5): track via TIDALAPI.track; album via TIDALAPI.album. A 404 album means "Saved with limited tags" (SaveNote.limitedTags, track's own details used); temporary errors past the retries throw .albumDetailsUnavailable (2.15).
3. Playback info (2.21, 2.23, 1.4, 1.6): ask for HI_RES_LOSSLESS. Temporary errors (5xx, 429, timeouts, dropped connections) are retried by the shared retry policy and NEVER cause a step down; step down to LOSSLESS (then HIGH for the AAC fallback, as the reference's quality chain does) only on a clear refusal for that quality (a 4xx other than 401/429 — record in needs_live_check that what TIDAL really answers is unverified). A sign-in rejection that persists after the keeper's one renewal throws .signInRejected. "Not available in your country"-style answers throw .notAvailable(reason:) with a short plain reason (raw server text only to the activity log). assetPresentation other than FULL throws .previewOnly (2.23). A transport failure that means no internet (RequestError.offline, or a captive-portal web page instead of JSON) throws .offline (1.7); a busy TIDAL past the retries throws .busy.
4. Manifest: TIDALManifest(playbackInfo:). Lossless → .flac; otherwise .m4a with SaveNote.savedAsAAC (2.10). Then folder.decide again with the real extension; a .skip returns it; .save gives the planned name and notes.
5. Space (2.20): before downloading, estimate the track's size (duration × the stream's bit rate; for FLAC use bitDepth × sampleRate × channels × ~0.7 when known, a generous Hi-Res default otherwise) and require about twice that free on the download folder's volume (volumeAvailableCapacityForImportantUsageKey); otherwise throw .diskFull(bytesNeeded:) with the shortfall.
6. Temporary file (2.2): download and tag in macOS's temporary folder ON THE SAME VOLUME as the download folder (FileManager.url(for: .itemReplacementDirectory, in: .userDomainMask, appropriateFor: folder, create: true)), never inside the download folder. A TemporaryDownloads registry records every temporary item the app makes (saved atomically with JSONFileStore at an injected path), removes it after success, failure or cancel, and exposes sweepLeftovers() for the next launch.
7. Audio (download-pipeline.md B7–B10): a .direct URL streams straight to the temporary file as it arrives (never whole in memory) with byte progress; .segments downloads the init and media segments with at most 8 in flight (a TaskGroup), each retried by the retry policy, written to the temporary file strictly in order (a small reorder buffer), progress by bytes or segments. Report progress 0…1, throttled to whole-percent changes. Cancellation (2.4, 2.13) stops at once: cancel the network tasks, delete the temporary file, throw CancellationError.
8. Cover (2.15): album cover at 1280 px; on "not found" try 640 then 320; none listed or not found at every size → save without it (SaveNote.withoutCoverArt); temporary errors past the retries → .coverUnavailable. A cover that isn't JPEG counts as no cover (log it). Fetch it concurrently with the audio.
9. Tags (spike part b, 2.7): title tag = title plus " (version)" unless the title already contains the version (case-insensitive, so never doubled); artist = TIDAL's artist names joined the way the reference does (download-pipeline.md B11); album, album artist, track number, disc (volumeNumber), year (first four characters of the album's releaseDate), copyright, ISRC. FLAC: FLACAudio(downloaded:) on the temporary file opened memory-mapped (Data(contentsOf:options:.alwaysMapped)), then FLACWriter.write to a second temporary file; unreadable audio throws .unreadableAudio. AAC: M4AWriting.writeM4A.
10. Length check (2.2): AudioProbe.inspect the written file; it must decode to its own declared end, and be within max(2 s, 1%) of TIDAL's duration when TIDAL lists one; otherwise throw .lengthMismatch(fileSeconds:tidalSeconds:). A "length unknown" verdict is never called damaged: fall back to the decoded length against TIDAL's.
11. folder.moveIntoPlace with the planned name; return .saved(fileName:quality:notes:) with SavedQuality from the STREAMINFO (bit depth, sample rate) or .aac, adding SaveNote.belowHiRes when request.expectsHiRes and the saved FLAC isn't Hi-Res (2.21).
Also: one public function that builds the FLACTags for a track (so the folder lane's 2.6 identity check and later code agree), and an end-to-end test for each stream kind on synthetic streams served by the mock URLProtocol: a BTS stream (bts-16-44100.flac), a DASH stream (split dash-24-96000.mp4), an AAC stream through a stand-in M4AWriting, plus tests for every error path above, cancellation mid-download (temporary file gone), a cut-off stream (lengthMismatch), disk full, the quality step-down rules, preview-only, and the skip-before-network rule.
