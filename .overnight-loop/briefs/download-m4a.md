# The AAC (.m4a) writer (lane m4a)

Files: new files in Sources/RobogearsCore/Download/ (for example M4AWriter.swift, MP4Boxes.swift); you may refactor the private box-reading helpers out of FMP4FLACExtractor.swift into a shared internal reader only if every existing test still passes unchanged; you may make the smallest change to Sources/RobogearsCore/Library/TagReader.swift's AVFoundation branch if that's needed to read back the ISRC you write. Tests in Tests/RobogearsCoreTests/M4A/.
Build a public M4AWriter that conforms to M4AWriting, with no FFmpeg. The spike (docs/spikes/audio-and-tagging.md part b "AAC .m4a output" and the AAC recommendation) found: Apple's passthrough export kept every AAC packet from a plain .m4a, but from a joined DASH (fragmented) AAC download only 43 of 45 packets. So:
1. Read the source: a plain (progressive) MP4 via its sample table (stsz, stsc, stco/co64, stts), or a fragmented MP4 (init moov + moof/mdat pairs, trun sample sizes/durations, tfhd/trex defaults) — one sample list (byte range + duration) either way; the AAC sample description (the stsd mp4a box with its esds) copied unchanged; keep the edit list / priming (elst) if the source has one, so the audio starts where the source says. Refuse encrypted or non-AAC tracks with a clear error.
2. Write a new progressive .m4a: ftyp (M4A ), moov with mvhd, one trak (tkhd, mdia: mdhd with the source timescale, hdlr soun, minf: smhd, dinf/dref, stbl: stsd copied, stts, stsc, stsz, stco or co64 as needed) and udta/meta/ilst tags, then mdat with the samples in order (stream them from the memory-mapped source; never hold a whole file in memory twice). Create the destination exclusively (O_EXCL) and delete your own partial file on any failure, as FLACWriter.write does.
3. Tags: the iTunes atoms FFmpeg wrote for the Electron app (spike part b lists them: title ©nam, artist ©ART, album artist aART, album ©alb, year ©day, copyright cprt, track trkn, disc disk, cover covr as JPEG, encoder ©too = FLACWriter.defaultToolName) from the FLACTags fields, PLUS the ISRC (D4 3.5: files this app saves carry it) as the freeform atom ----:com.apple.iTunes:ISRC. Empty values are left out; a track or disc number of 0 is left out.
4. Return M4AWriteResult with the duration computed from the written sample durations (minus priming per the edit list).
Prove it: tests that convert aac-320.m4a (plain) and dash-aac.mp4 (fragmented) and check every source packet survives byte for byte (compare the sample bytes), the duration matches, AVFoundation (AVURLAsset + AVAssetReader) opens and decodes the output to the end, TagReader reads back title, artist and ISRC, the cover is present as JPEG, an existing destination is never replaced, and a failure mid-write leaves no file. Compare the tag atom set with ffmpeg-aac.m4a's (the Electron output) and explain any difference in the result's deviations. ffmpeg and ffprobe are installed at /opt/homebrew/bin and may be used to cross-check while you work, but the committed tests must not need them.
